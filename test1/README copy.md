# MOOVE — แอปเช่ารถ

โปรเจกต์ตัวอย่าง Flutter สำหรับนักศึกษาวิทยาการคอมพิวเตอร์ชั้นปีที่ 2 ทำเป็นต้นแบบแอปเช่ารถภาษาไทย ใช้ข้อมูลจำลองและไม่ต้องเชื่อมต่อ API

## 9 หน้าของแอป

1. หน้าแรก — ค้นหารถและดูรถแนะนำ
2. ค้นหารถ — ค้นหาชื่อรถและเลือกหมวดหมู่
3. รถที่บันทึก — ดูรายการโปรด
4. รายละเอียดรถ — ดูข้อมูลและเริ่มจอง
5. เลือกการจอง — เลือกวันรับรถ วันคืนรถ และจุดรับรถ
6. ชำระเงิน — เลือกช่องทางชำระเงินจำลอง
7. จองสำเร็จ — แสดงสรุปการจอง
8. การจองของฉัน — ดูรายการจองที่ทำในแอป
9. โปรไฟล์ — ดูข้อมูลผู้ใช้และเมนูตั้งค่า

## วิธีเปิดโปรเจกต์

1. เปิดโฟลเดอร์ `app` ด้วย VS Code
2. เปิด Terminal ใน VS Code
3. พิมพ์ `flutter pub get`
4. เชื่อมต่อ Emulator หรือโทรศัพท์ แล้วพิมพ์ `flutter run`

แอปใช้เฉพาะ Flutter SDK และ Material Icons ไม่มีแพ็กเกจภายนอก ข้อมูลรถ ราคา และการชำระเงินเป็นข้อมูลตัวอย่างสำหรับสาธิตการทำงานเท่านั้น
